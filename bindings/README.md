# The bindings

One wrapper file and one skill per language over the C ABI in [c/](c/): [cpp/](cpp/), [python/](python/), [dotnet/](dotnet/), [java/](java/) and [android/](android/), [js/](js/), [swift/](swift/), [go/](go/), [php/](php/). Each folder's `SKILL.md` is its tutorial and the one document an LLM integrates from; the host contract they all share is the top comment of [c/mudrpc.h](c/mudrpc.h).
