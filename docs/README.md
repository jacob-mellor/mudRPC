# The pages, and the phrase each owns

Each page here owns one phrase people type, in its slug, its title and its first paragraph; no two pages compete for one. Long-tail pages link up to their silo's root, and the root to the [home page](../README.md); every link to a page uses its phrase as the anchor text. The same map rules the other properties at publication: an article posted on several sites names one original by `rel=canonical`.
