# The standard scenarios and their logs

`<name>.scenario` is a world in the format [adapters/SKILL.md](../adapters/SKILL.md) gives, `<name>.log` what every harness in every language must print byte for byte when it plays it, and `.signed.log` or `.gcm.log` where a sealer changes the log. A log is regenerated with the `scenario` example and its diff reviewed, never accepted blind.
